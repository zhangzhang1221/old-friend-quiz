# 《后会友期》旧友人格测试

非官方二创 · 娱乐向人格测试。16 道题，测出你是这档节目里的谁，并给出对应的关系分析。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 交互版问卷：单文件、无依赖，浏览器直接打开，自动计分并出结果 |
| `后会友期-旧友人格测试（印刷版）.pdf` | 15 页印刷版：封面、题目、计分表、8 种人格解析、4 组关系 |
| `print.html` | 印刷版的 HTML 源文件（A4 样式，可用浏览器「打印为 PDF」重新导出） |
| `build.mjs` | 构建脚本：校验数据、生成 `index.html` 与 `print.html` |
| `src/data.mjs` | 全部文案与计分权重（题目、八种人格、四组关系） |
| `src/app.html` | 交互版的模板（`__DATA__` 占位，构建时注入数据） |

## 使用

交互版：双击 `index.html` 即可。支持键盘：`A–D` / `1–4` 选择，`←` / `Backspace` 返回上一题。

印刷版：直接打印 PDF，或打印 `print.html`。每题末尾有「我的选择」勾选行，做完翻到第 6 页按计分表累加。

## 计分规则

- 16 道题，每题 4 个选项，每个选项对应一个**主选角色（2 分）**和一个**次选角色（1 分）**。
- 八位角色在 16 题中各有 8 次主选、8 次次选，**满分均为 24 分**，不存在结构性偏袒。
- 得分最高者即结果；同分时比较主选命中次数，再以答案指纹做确定性随机，避免位置偏袒。
- 4 章场景依次改编自节目里的真实处境：重逢、同行、对质、和解。

## 八种人格

1. 张萌 · 主动型修补者
2. 马天宇 · 温柔的回避者
3. 厉娜 · 直给的讨说法者
4. 许飞 · 讲逻辑的守夜人
5. 文吉儿 · 带账本的掌控者
6. 王子璇 · 醒来的付出者
7. 青稚 · 硬撑的懂事者
8. 白小纯 · 嘴硬的直球者

每人包含：关系里的样子、裂缝从哪来、一句说不出口的台词、和好路线、合拍 / 翻车、节目片段参照。另有四组关系结构解析（张萌×马天宇、厉娜×许飞、文吉儿×王子璇、青稚×白小纯）。

## 修改内容

改 `src/data.mjs`（文案与权重），然后运行：

```bash
node build.mjs
```

构建时会校验：每题 4 个选项、权重为主 2 次 1、每题主选不重复、每位角色恰好 8 主 8 次。校验不通过会直接报错。

重新导出 PDF：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --no-sandbox --no-pdf-header-footer \
  --virtual-time-budget=3000 \
  --print-to-pdf="后会友期-旧友人格测试（印刷版）.pdf" \
  "file://$PWD/print.html"
```

## 说明与出处

本测试与节目及嘉宾无关。人格设定基于节目公开播出的片段与公开讨论，指向关系类型，不构成对任何真实个人的评价，也不构成心理诊断；结果仅供娱乐与自我观察。
